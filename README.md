# Double Daily American Blog Tube

Companion blog for the **Originals 2U** YouTube channel — twice-daily American
documentaries (9:00 AM and 4:00 PM, America/Chicago), facts only, every fact
sourced and credited, all illustrations original.

Live site: https://lodestar010.github.io/double-daily/

Pure static HTML/CSS, generated by two small Python scripts (stdlib only).
No frameworks, no trackers, no ads.

## Site title

The site name lives in ONE place: the `site_title` value in `config.json`.
Edit it, run `python3 build.py`, commit, push — the rename is done.

## Add a post

Write a small JSON data file with these fields:

```json
{
  "title": "GTA 6 — Past, Present, and What Comes Next",
  "youtube_id": "dQw4w9WgXcQ",
  "slot": "PM",
  "date": "2026-10-19",
  "summary": "One line shown on the home page.",
  "body": "The write-up. A blank line separates paragraphs.",
  "company": {"name": "Nvidia", "text": "The company segment, in facts."},
  "sources": [
    {"name": "Rockstar Games — official announcement", "url": "https://..."},
    {"name": "Take-Two Interactive — earnings release", "url": "https://..."}
  ]
}
```

Then run:

```
python3 add_post.py path/to/post-data.json
```

That writes `posts/<date>-<slot>-<slug>.json`, regenerates `index.html`,
`about.html`, and every post page, and prints the new post's path.

Publish by committing and pushing:

```
git add -A && git commit -m "Post: <title>" && git push
```

GitHub Pages rebuilds automatically (usually a minute or two).

## Rebuild without adding a post

```
python3 build.py
```

## Layout

- `config.json` — site title (single rename point), tagline, channel link
- `build.py` — regenerates the whole site from `posts/*.json` + `templates/`
- `add_post.py` — the post generator (see above)
- `templates/` — page shell, post page, home-page card
- `posts/` — one JSON data file (source of truth) + one generated HTML page per post
- `index.html`, `about.html`, `style.css` — generated home/about + hand-written CSS
